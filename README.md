# 📊 Analyse Mathématique d'une Fonction en Python

Ce projet Python permet d’effectuer automatiquement une étude complète d’une fonction mathématique.

---

# ✨ Fonctionnalités

Le programme permet de :

- Définir une fonction mathématique
- Calculer la dérivée
- Trouver le domaine de définition
- Déterminer les intervalles :
  - croissants
  - décroissants
- Détecter :
  - les maximums locaux
  - les minimums locaux
- Afficher le graphique de la fonction

---

# 🛠 Technologies utilisées

- Python
- SymPy
- NumPy
- Matplotlib

---
